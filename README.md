## 🧠 Sobre mim

Sou desenvolvedora backend com forte viés arquitetural e orientação a resultado. Trabalho na construção de APIs escaláveis, pipelines de dados e sistemas de IA aplicada, com foco em confiabilidade, cobertura de testes e entrega real em produção.

Atualmente desenvolvo projetos que envolvem:

* Arquitetura hexagonal e domain-driven design com domínios desacoplados
* Pipelines de valuation financeiro automatizado com simulação Monte Carlo e integração de dados de mercado
* Sistemas multi-agent com LangGraph para geração e validação de assets com IA
* Workers assíncronos, filas e arquiteturas white-label para SaaS B2B
* Integração com LLMs (OpenRouter, Gemini, Ollama) em contextos de produto real

Trato software como sistema vivo: projetado para ser auditável, testável e evoluir sem quebrar o que já funciona.

## 🛠️ Áreas de foco
